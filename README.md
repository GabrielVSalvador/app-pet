# 🐾 PetWalk

Aplicativo mobile de serviços para pets — passeios, petshops e produtos, tudo em um só lugar.

## 📱 Funcionalidades

- **Passeios** — encontre passeadores próximos no mapa, solicite imediatamente ou agende
- **Petshops** — agende banho, tosa e consultas veterinárias
- **Produtos** — compare preços de rações, remédios e acessórios entre lojas

## 🛠️ Tecnologias

- HTML, CSS e JavaScript (fase atual — fundamentos)
- React Native + Expo (fase 3 — app mobile)
- Supabase (fase 4 — banco de dados)
