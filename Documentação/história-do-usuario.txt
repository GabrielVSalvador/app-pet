🎯 2. CASOS DE USO
🧠 Caso de uso: Solicitar passeio imediato

Ator: Usuário
Fluxo principal:

Usuário abre app (tela mapa)
Visualiza passeadores próximos
Clica em "Solicitar passeio"
Escolhe opção "Mais rápido"
Sistema envia solicitação para passeadores próximos
Um passeador aceita
Sistema inicia rastreamento em tempo real
Passeio é finalizado
Usuário avalia
🧠 Caso de uso: Agendar passeio
Usuário seleciona data/horário
Sistema envia solicitação
Passeador aceita
No horário → inicia rastreamento
Finaliza → avaliação
🧠 Caso de uso: Agendar serviço
Usuário entra em "Serviços"
Escolhe tipo (banho, tosa…)
Escolhe petshop
Escolhe horário disponível
Confirma agendamento
Sistema salva e mostra próximo serviço
Após serviço → avaliação
🧠 Caso de uso: Buscar produto
Usuário entra em "Produtos"
Digita produto
Sistema lista lojas
Mostra:
preço
entrega
retirada
Usuário escolhe
